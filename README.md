# Романтическое приглашение

Одностраничная интерактивная открытка на 5 месяцев отношений. Проект собран mobile-first: основной сценарий рассчитан на iPhone, но полноценно работает и на больших экранах.

## Установка и запуск

Нужен Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Локальная версия откроется по адресу `http://localhost:3000`.

## Production build

```bash
npm run build
```

## Публикация на Netlify

Проект сохраняет исходную Sites-сборку, но дополнительно имеет отдельную статическую сборку для Netlify.

Если репозиторий подключён к Netlify, настройки автоматически читаются из `netlify.toml`:

- Build command: `npm run build:netlify`
- Publish directory: `netlify-dist`
- Node.js: `22.13.0`

Для локальной проверки Netlify-сборки:

```bash
npm run build:netlify
```

После push Netlify должен автоматически запустить новую сборку. Если настройки проекта были введены вручную ранее, очистите их или установите значения из списка выше.

## Где менять содержимое

Все основные редактируемые данные находятся в `src/data/content.ts`:

- время — поле `time`;
- дата или подпись дня — поле `dateLabel`;
- обращения и подпись — `addressee` и `signature`;
- тексты приглашения — массив `invitation`;
- подписи и порядок фотографий — `gallery` и `story`;
- карточки-подсказки — `hints`.

## Фотографии

Добавляйте фотографии в `public/photos/`, затем пропишите путь, размеры и описание в `src/data/content.ts`. Для вертикальных снимков можно использовать `layout: "portrait"`, для широких — `layout: "wide"`. Поле `position` управляет кадрированием лица.

## Шрифты

Локальные файлы лежат в `public/fonts/`. Подключение `@font-face` находится в `app/globals.css`. Если имя файла изменится, обновите соответствующий `url(...)`.

## Музыка

Автовоспроизведение намеренно отключено. Если понадобится музыка, положите файл в `public/audio/our-song.mp3` и добавьте пользовательский контрол воспроизведения в `app/LoveInvitation.tsx`.

## AI-изображение

Художественная открытка находится в `public/og.png` и одновременно используется для красивого превью ссылки. Секция управляется полем `ai.enabled` в `src/data/content.ts`: установите `false`, чтобы скрыть её, или замените `ai.image`, чтобы использовать другое изображение.
